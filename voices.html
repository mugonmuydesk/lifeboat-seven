01 / Choose a voice

Changes how the model speaks. Regenerate to hear the difference.

What can I adjust?

Voice, speaking speed and the text itself are the model’s controls here. Punctuation changes phrasing and pauses. There is no native emotion, pitch or “sarcasm” slider. Volume is a playback setting.

This explorer uses the CPU / WebAssembly backend for the 8-bit model. Character samples change only the text, so you can audition the same line with different voices.

02 / Give them a line
